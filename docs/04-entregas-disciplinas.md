# 04 — Entregas das disciplinas

Todas as disciplinas se relacionam ao Colecity.

| Disciplina | Entrega relacionada ao Colecity | Responsável |
| --- | --- | --- |
| C# Software Development | API de domínio em C#/.NET com as regras de negócio. | Silas |
| SOA e Web Services | Mesma API de domínio da disciplina de C#. | Silas |
| Mobile Development & IoT | App Expo da jornada do cidadão e BFF mobile (Node + TypeScript na Vercel). | Responsável por Mobile e Testing |
| Testing, Compliance & Quality Assurance | Features e Test Cases no Azure Boards, baseados nas regras do doc 07. | Responsável por Mobile e Testing |
| Inteligência Artificial & Machine Learning | Pergunta de ML com dados públicos ligada ao problema; citada no README e no pitch. | Colega da disciplina |
| Physical Computing | Circuito ESP32 no Wokwi ligado ao problema; citado no README e no pitch. | Colega da disciplina |
| Operating Systems | Infraestrutura Linux que hospeda a API de domínio. | Colega da disciplina |
| Cybersecurity | Módulo, auditoria e painel da disciplina. | Colega da disciplina |

## Escopo de Testing

Testing cobre o ecossistema da plataforma (app, BFF e API de domínio), incluindo as regras de segurança e privacidade que fazem parte do app (login, permissões, LGPD). Cybersecurity, Physical Computing, Operating Systems e IA não entram nas Features e Test Cases.
