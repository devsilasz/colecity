# 05 — Testing e critérios de aceite

## Entrega (Testing, Compliance & Quality Assurance)

- Features da aplicação com descrição e critérios de aceite no **Azure Boards**.
- Test Cases funcionais, caixa-preta, positivos e negativos, com objetivo, preparação, entradas, passos e resultados esperados.
- Professor incluído como **Admin** no projeto do Azure; link do projeto no PDF.
- Prints das telas com a relação de Features, os detalhes de cada Feature e os Test Cases, reunidos em um único documento exportado em **PDF**.
- Avaliação: Features 50%, Test Cases 50%.
- Prazo: 19/11, 23h55, no Teams.

## Método

- Cada Feature corresponde a um módulo ou funcionalidade do doc 07.
- Critérios de aceite referenciam os códigos das regras (RN-XXX-NN).
- Cada critério tem pelo menos um Test Case positivo e, quando aplicável, negativo.
- Rastreabilidade: Feature → critério → regra → Test Case.
- Test Cases não são registrados como executados ou aprovados sem evidência.
